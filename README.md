🚆 RailMate

RailMate is a modern Indian railway companion designed to make train travel simpler and smarter.

✨ Features

- 🔎 Train search & journey planning
- 🎫 PNR status
- 🚉 Station information
- 🤖 AI-powered railway assistant
- 📊 Railway insights and useful travel information
- 📱 Modern, responsive UI

🛠️ Tech Stack

- Frontend: Next.js, React, TypeScript
- Styling: Tailwind CSS
- Icons: Lucide React
- Backend/API: Node.js / Railway APIs
- AI: Gemini

📁 Project Structure

railmate/
├── app/
├── components/
├── lib/
├── public/
└── package.json

🚀 Getting Started

git clone <your-repository-url>
cd railmate
npm install
npm run dev

Open http://localhost:3000 in your browser.

📌 Status

RailMate is currently under active development. Some railway APIs and AI features are being integrated.
